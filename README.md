# Controle de Estoque
## Descrição

Este projeto é um programa simples desenvolvido em Python para controle de estoque. Ele permite atualizar a quantidade de produtos, adicionar produtos ao estoque e exibir as quantidades disponíveis.

## Tecnologias utilizadas
Python
Visual Studio Code

## Como instalar e executar

Instale o Python no computador.
Abra o projeto no Visual Studio Code.
Crie ou abra o arquivo estoque.py.
Cole o código do projeto no arquivo.
Salve o arquivo.
Execute o programa pelo Visual Studio Code ou pelo terminal utilizando:
python estoque.py

## Exemplo de uso / Demonstração

O estoque inicial do programa é:

**estoque = [20, 15, 10, 30, 5]**

O programa realiza algumas operações:

atualizar_estoque(estoque, 0, 3)
atualizar_estoque(estoque, 3, 2)
adicionar_estoque(estoque, 4, 10)

Essas operações retiram produtos do estoque e adicionam quantidade a outro produto.

Ao final, a função exibir_estoque() mostra as quantidades disponíveis no terminal.
